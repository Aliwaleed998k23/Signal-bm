# بوت إشارات الخلفية (Biquote Signal Bot)

يفحص عدة أزواج تلقائياً كل 5 دقائق عبر GitHub Actions ويرسل صورة صفقة لتيليجرام
فور رصدها — **بدون الحاجة لفتح التطبيق أو أي متصفح**. يعمل على سيرفرات GitHub
مباشرة، حتى لو موبايلك مطفي.

---

## خطوات التفعيل (مرة واحدة فقط)

### 1) أنشئ مستودع (Repository) على GitHub
- افتح https://github.com/new
- اختر اسم للمستودع (مثلاً `signal-bot`)
- اختره **Private** (خاص) — أفضل لأنه سيحتوي على إعدادات حساسة لاحقاً كـ Secrets
- اضغط Create repository

### 2) ارفع هذه الملفات للمستودع
أسهل طريقة من المتصفح مباشرة (بدون git):
- بصفحة المستودع الفارغة اضغط "uploading an existing file"
- اسحب كل ملفات هذا المجلد وارفعها (حافظ على نفس أسماء الملفات والمجلدات، خصوصاً
  مجلد `.github/workflows/scan.yml`)
- اضغط Commit changes

أو عبر سطر الأوامر إذا تفضل ذلك:
```bash
cd signal-bot
git init
git add .
git commit -m "init signal bot"
git branch -M main
git remote add origin https://github.com/USERNAME/signal-bot.git
git push -u origin main
```

### 3) أضف بيانات تيليجرام كـ Secrets (سرية، لا تُكتب بالكود مباشرة)
- بصفحة المستودع: **Settings → Secrets and variables → Actions → New repository secret**
- أضف اثنين:
  - `TELEGRAM_BOT_TOKEN` = التوكن الذي حصلت عليه من @BotFather
  - `TELEGRAM_CHAT_ID` = الـ Chat ID (نفس الطريقة المستخدمة بالتطبيق: افتح البوت،
    اضغط Start وأرسل أي رسالة، ثم افتح هذا الرابط بالمتصفح بعد تعويض التوكن:
    `https://api.telegram.org/bot<TOKEN>/getUpdates` وابحث عن `"chat":{"id":...}`)

### 4) عدّل الأزواج المراقبة (اختياري)
افتح ملف `config.js` وعدّل قائمة `PAIRS` حسب ما تريد مراقبته. الافتراضي:
XAU/USD، EUR/USD، GBP/USD، USD/JPY، XAG/USD — على فريمات 1M/5M/15M/1H.

### 5) فعّل GitHub Actions
- افتح تبويب **Actions** بالمستودع
- إذا ظهرت رسالة تفعيل، اضغط "I understand my workflows, go ahead and enable them"
- ستجد workflow باسم **Signal Scan** يعمل تلقائياً كل 5 دقائق من الآن فصاعداً

### 6) اختبار فوري (بدون انتظار)
- من تبويب Actions اختر **Signal Scan** → **Run workflow** → **Run workflow**
- راقب السجل (Logs)؛ إذا كل شي مضبوط سترى "✓ أُرسلت الصورة لتيليجرام" عند وجود صفقة،
  أو رسالة تفيد أنه لا توجد صفقة مؤهلة حالياً.

## ملاحظات مهمة

- **التوقيت**: أقل فاصل زمني مسموح به لـ GitHub Actions هو 5 دقائق تقريباً (وأحياناً
  يتأخر التنفيذ الفعلي دقيقة أو دقيقتين حسب ازدحام سيرفرات GitHub — غير مؤثر لأننا
  نراقب فريمات 5 دقائق فأعلى).
- **منع التكرار**: يحتفظ الملف `state.json` بآخر صفقة أُرسلت لكل زوج/فريم، ويُحدَّث
  تلقائياً بعد كل تشغيل (commit تلقائي) — فلن تصلك نفس الصفقة مرتين.
- **مجاني بالكامل**: GitHub Actions يمنح دقائق تشغيل مجانية كافية جداً لهذا الاستخدام
  (المستودعات الخاصة تحصل على 2000 دقيقة/شهر مجاناً، وهذا الفحص يستهلك ثوانٍ قليلة
  فقط بكل تشغيل).
- **مستقل تماماً عن التطبيق**: هذا البوت لا علاقة له بملف `analyzer.html` — يعمل بشكل
  منفصل تماماً على سيرفرات GitHub، لذلك يستمر حتى لو التطبيق أو المتصفح أو الموبايل
  مغلق بالكامل.
- إذا احتجت تغيير عدد الشموع، إعدادات المؤشرات (RSI/MACD/EMA...)، أو أقل R:R مقبول،
  عدّلها من `config.js` مباشرة — لا حاجة لمس باقي الملفات.
